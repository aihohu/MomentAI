# MomentAI · 迹录时刻

[English](README.md) · [官网](https://moment.hohu.org) · [GitHub](https://github.com/aihohu/MomentAI)

**让声音、画面与思考留下轨迹。**

迹录时刻是一款面向 iOS 和 Android 的本地录音笔记应用。录制音频，在设备上转写，
让照片、随想和重点保留在同一条时间线上。可选 AI 总结与对话使用你指定的服务商和 API Key。

## 开始使用

阅读[使用指南](docs/USAGE.zh-CN.md)，完成录音、回放、导出与导入，并了解权限及数据保留边界。
[文档目录](docs/README.zh-CN.md)按使用者、开发者和维护者组织阅读顺序。

## 功能与隐私

支持本地录音与转写、照片和随想、重点、搜索，以及可选的远程 AI 总结与对话。
[使用指南](docs/USAGE.zh-CN.md#功能与隐私)说明支持范围、数据去向及当前限制。
