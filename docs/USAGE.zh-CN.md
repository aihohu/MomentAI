# 使用与保护记录

[English](USAGE.md) · [文档目录](README.zh-CN.md)

在 [GitHub Releases](https://github.com/aihohu/MomentAI/releases) 查看已发布安装包及安装说明。
如果你的平台没有可用安装包，按[构建指南](BUILDING.zh-CN.md)从源码构建。Git 不包含模型权重、编译后的应用或签名凭据。

1. 点击**开始记录**并允许麦克风访问。内置普通话轻量模型可离线使用；可选下载可以选择**稍后**。
2. 添加照片、随想或重点，按需使用**暂停录音**和**继续录音**。暂停不会在已保存音频中加入静音。
3. 点击**结束并保存**，等待完成后回放。以后从**记录**页打开，点击时间线条目可从对应音频位置回听。
4. 传输一条完整记录时，选择**记录操作 → 分享与导出 → 生成导出包**，校验完成后分享 `.momentai` 文件。
5. 接收端在**记录**页选择**导入完整记录**，选中原文件，查看预览后点击**确认导入并打开**。

iPhone 可通过分享菜单的**存储到文件**保存；Android 使用可用的文件提供方。
如果 Android 没有本地下载目录选项，可选择其他本地文件提供方，或通过可信的分享目标传输。
删除源记录前，核对导入音频、照片和文字。保留原始归档，不重新压缩、加密或分卷；上限为 2 GiB。

## 功能与隐私

- 录音、暂停与继续、中断恢复和按音频位置回放。
- 本地转写，可选全文精修、说话人标记，以及记录搜索。
- 原始音频位置上的照片、随想和重点；文本、Markdown、WAV 和完整 `.momentai` 记录导出导入。
- 中英文界面，可选 AI 总结与对话。

录音和本地语音分析保存在应用私有容器中。通过**设置 → 转写模型**管理可选模型，
下载会访问模型来源服务。远程 AI 经确认后向你指定的服务商发送文字与上下文，不附带音频或照片。
API Key 使用系统安全存储。`.momentai` 不含密钥、模型文件、AI 对话或应用设置。
文件提供方可能使用自己的云存储。卸载或清除数据前导出重要记录，不要依赖系统备份保存所有应用内容。
Android 录音位于不参与系统备份的存储区；iOS 录音位于 Application Support，Documents 用于交换文件。
两端的系统备份行为不同。

构建目标为 Android ARM64（API 24+）和 iOS（15+），不表示已验证所有设备。
实际支持范围与限制见对应版本的发布说明。当前没有正文手工纠错、云同步、OCR、跨记录说话人识别，
也不支持导入 `.tracenote`。

## 权限与首次录音验证

在测试设备上录制一句无敏感信息的短句。录音必须获得麦克风权限，拍照才需要相机权限。
拒绝后，在系统设置中找到迹录时刻，开启所需权限并重试。Android 使用麦克风前台服务，
在支持的系统版本申请通知权限；通知权限不能代替麦克风权限。

保存后确认短句可回听、时间线能跳转到对应音频位置、照片和随想已保留。
转写可能不准确，应保留原始音频。发生中断时，先检查界面状态及恢复入口，再开始新录音。
不能假定来电或系统终止后后台仍在录音。空间不足导致保存失败时，释放无关文件占用后重试或重新进入恢复；
不要通过清除应用数据恢复录音。

## 可选 AI

打开**设置 → AI 服务**，添加服务，选择 OpenAI Compatible 或 Anthropic Messages，
填写服务商的 HTTPS API 基础地址和密钥，添加服务商提供的准确模型 ID 并保存。
在已保存记录中打开 AI 总结或对话，选择配置的模型，核对文字上下文和授权提示后提交。
配置保存成功本身不能证明服务商兼容或账户余额充足。

基础地址不能包含内嵌凭据、查询参数或片段。认证或模型错误时，向对应服务商核对密钥、地址和模型 ID；
不要把密钥贴入 Issue。取消会停止本地处理，服务商仍可能计费。AI 输出需要人工核对，不能代替原始音频。

## 验证传输结果

用一条简短的合成测试记录按上述步骤导出、导入。在接收设备核对回放时长、已知音频位置、文字和照片。
归档被拒绝时，重新传输未重新打包的原始 `.momentai` 文件，验证前保留源记录。
导入创建副本，不提供同步。卸载或清除数据后若没有导出包，本应用没有云端恢复服务。
可复现问题按[贡献指南](../CONTRIBUTING.md)报告。
