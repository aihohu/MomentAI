# Documentation

[简体中文](README.zh-CN.md) · [Documentation](README.md)

These guides describe the implementation at the selected source revision. Application
version comes from [pubspec.yaml](../pubspec.yaml), currently `0.1.0+12`; packaged
compatibility and device coverage belong to that release's notes. This repository
has no documentation-site build; the website link in README is not a generated copy.

| Contributor | [Contribute](../CONTRIBUTING.md), [maintain documentation](MAINTAINING.md) |
| Maintainer | [Test](TESTING.md), [prepare a release](RELEASING.md) |

[Security reporting](../SECURITY.md), [community policy](../CODE_OF_CONDUCT.md), and
[third-party notices](../THIRD_PARTY_NOTICES.md) remain repository policies. Their
English texts are authoritative. Each task guide links directly to its translation.
The [publication manifest](manifest.json) lists first-party public prose; it is an
inclusion list, not proof of independent review. Code references are hand-curated,
not a generated or stable public SDK/API reference.
