# MomentAI

[简体中文](README.zh-CN.md) · [Website](https://moment.hohu.org) · [GitHub](https://github.com/aihohu/MomentAI)

**Let sound, images, and thoughts leave a trace.**

MomentAI (迹录时刻) is a local recording notebook for iOS and Android. Record audio,
transcribe on your device, and keep photos, notes, and highlights on one timeline.
Optional AI summaries and conversations use a provider and API key you choose.

## Get started

Follow the [user guide](docs/USAGE.md) to record, replay, export, and import, including
permissions and data retention. The [documentation index](docs/README.md) provides
reading paths for users, developers, and maintainers.

## Features and privacy

Local recording and transcription, photos, notes, highlights, search, and optional
remote AI summaries and conversations are supported. See the
[user guide](docs/USAGE.md#features-and-privacy) for scope, data flows, and limitations.
